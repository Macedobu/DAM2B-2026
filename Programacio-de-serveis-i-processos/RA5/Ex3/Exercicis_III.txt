1. Resol les següents operacions:

a) 347 + 513 ≡ ? (mod 763).

347 + 513 -763 = 97

347 + 513 ≡ 860 ≡ 97 (mod 763)

----

b) 3274 + 1238 + 7231 + 6437 ≡ ? (mod 9254).

3274 + 1238 + 7231 + 6437 - 9254 = 8926

3274 + 1238 + 7231 + 6437 ≡ 18180 ≡ 8926 (mod 9254)

----

c) 153 * 287 ≡ ? (mod 353).

153 * 287 = 43911
43911 // 353 = 124
353 * 124 = 43772
43911 - 43772 = 139

153 * 287 ≡ 139 (mod 353)

----

d) 357 * 862 * 193 ≡ ? (mod 943).

357 * 862 = 307734
307734 // 943 = 326
943 * 326 = 307418
307734 - 307418 = 316

316 * 193 = 60988
60988 // 943 = 64
943 * 64 = 60352
60988 - 60352 = 636

357 * 862 * 193 ≡ 636 (mod 943)

----

e) 5327 * 6135 * 7139 * 2187 * 5219 * 1873 ≡ (mod 8157).
(Pista. Després de cada multiplicació redueix módul 8157 abans de fer la següent multiplicació)

5327 * 6135 = 32681145
32681145 // 8157 = 4006
8157 * 4006 = 32676942
32681145 - 32676942 = 4203

4203 * 7139 = 30005217
30005217 // 8157 = 3678
8157 * 3678 = 30001446
30005217 - 30001446 = 3771

3771 * 2187 = 8247177
8247177 // 8157 = 1011
8157 * 1011 = 8246727
8247177 - 8246727 = 450

450 * 5219 = 2348550
2348550 // 8157 = 287
8157 * 287 = 2341059
2348550 - 2341059 = 7491

7491 * 1873 = 14030643
14030643 // 8157 = 1720
8157 * 1720 = 14030040
14030643 - 14030040 = 603

5327 * 6135 * 7139 * 2187 * 5219 * 1873 ≡ 603 (mod 8157)

----

f) 137² ≡ ? (mod 327).

137² = 18769
18769 // 327 = 57
327 * 57 = 18639
18769 - 18639 = 130

137² ≡ 130 (mod 327)

----

g) 373⁶ ≡ ? (mod 581).

373² = 139129
139129 // 581 = 239
581 * 239 = 138859
139129 - 138859 = 270

373⁶ ≡ (373²)³ ≡ 270³
270³ = 19683000
19683000 // 581 = 33877
581 * 33877 = 19682537
19683000 - 19682537 = 463

373⁶ ≡ 463 (mod 581)

----

h) 23³ * 19⁵ * 11⁴ ≡ ?  (mod 97)

Aquesta operació la separarem en 4 blocs.

Bloc 1 = 23³

23³ = 12167
12167 // 97 = 125
97 * 125 = 12125
12167 - 12125 = 42

Bloc 2 = 19⁵

19⁵ = 19 * 19⁴ = 19 * (19²)²
19² = 361
361 // 97 = 3
97 * 3 = 291
361 - 291 = 70

70² = 4900
4900 // 97 = 50
97 * 50 = 4850
4900 - 4850 = 50

50 * 19 = 950
950 // 97 = 9
97 * 9 = 873
950 - 873 = 77

Bloc 3 = 11⁴

11⁴ = (11²)²
11² = 121
121 // 97 = 1
97 * 1 = 97
121 - 97 = 24

24² = 576
576 // 97 = 5
97 * 5 = 485
576 - 485 = 91

Bloc 4

23³ * 19⁵ * 11⁴ ≡ 42 * 77 * 91 ≡ ?  (mod 97)

42 * 77 = 3234
3234 // 97 = 33
97 * 33 = 3201
3234 - 3201 = 33

33 * 91 = 3003
3003 // 97 = 30
97 * 30 = 2910
3003 - 2910 = 93

23³ * 19⁵ * 11⁴ ≡ 93  (mod 97)
